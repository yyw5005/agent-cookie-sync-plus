Which sites

Sealed export

With a passphrase set, every export is sealed with AES-256-GCM before it reaches the sync folder. The folder then holds ciphertext only: whoever moves the file never sees a live session. The passphrase itself stays in this browser and is never exported. Your agent needs the same passphrase to unseal (inject-cookies.py --passphrase-env).

Only sites used recently

Chrome does not record when a cookie was created, so this reads your browsing history (asked for once, read locally) plus the cookie changes this extension has seen since it was installed.

Timing

The scheduled run is a heartbeat: if nothing changed since the last export, the files are left alone. On demand at any time: click the toolbar icon, or run Request-Sync.ps1 / request-sync.sh. Every export is appended to export.log in the sync folder.
